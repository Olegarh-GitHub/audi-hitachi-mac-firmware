# Hitachi HD63B03XP — распиновка, 64 вывода

**Корпус DP-64S.** В заводском даташите один чертёж объединяет HD6303XP, HD63A03XP и HD63B03XP. Для варианта **B** максимальная частота системной шины **E — 2 МГц** при питании 5 В ±10 %. Это соответствует частоте кварца 8 МГц. [Даташит Hitachi, стр. 86–87](https://www.jaapsch.net/psion/pdffiles/hd6303X_datasheet.pdf#page=1)

**Как считать ножки.** Смотреть сверху, со стороны маркировки. Повернуть корпус так, чтобы точка-ключ была в левом верхнем углу. Слева возле точки находится **1 (VSS)**, напротив него справа — **64 (E)**. По левому ряду счёт идёт вниз до **32 (P67)**, затем по правому ряду вверх от **33 (VCC)** до **64**. При взгляде со стороны пайки расположение зеркальное. [Чертёж корпуса, стр. 87, верхний левый рисунок](https://www.jaapsch.net/psion/pdffiles/hd6303X_datasheet.pdf#page=2)

## Ножки 1–64

Косая черта **перед** именем сигнала заменяет надчёркивание в оригинале. Например, `/RD` активен при низком уровне. Для портов первой указана основная функция ножки, в скобках — функция встроенного таймера, последовательного интерфейса или контроллера шины. Направление дано со стороны процессора.

| Ножка | Обозначение | Направление | Назначение |
|---:|---|---|---|
| 1 | `VSS` | Питание | Общий провод (0 В). Второй вывод VSS — ножка 42. Hitachi предписывает соединять с землёй оба. |
| 2 | `XTAL` | Генератор | Вывод встроенного генератора для подключения кварца. Если тактирование подают извне на EXTAL, XTAL оставляют свободным. |
| 3 | `EXTAL` | Вход генератора | Второй вывод для подключения кварца. Сюда же подают сигнал внешнего генератора. |
| 4 | `MP0` | Вход | Выбор режима работы, младший бит. Для рабочего режима MPU Hitachi задаёт высокий уровень. |
| 5 | `MP1` | Вход | Выбор режима работы, старший бит. Для рабочего режима MPU Hitachi задаёт низкий уровень. |
| 6 | `/RES` | Вход | Аппаратный сброс, активен при 0. После снятия сброса процессор загружает адрес старта из ячеек $FFFE и $FFFF. |
| 7 | `/STBY` | Вход | Аппаратный режим ожидания. При 0 генератор останавливается. Для обычной работы нужен высокий уровень. |
| 8 | `/NMI` | Вход | Немаскируемое прерывание по спаду 1 → 0. Вектор хранится в $FFFC–$FFFD. |
| 9 | `P20` (`Tin`) | Ввод/вывод | Порт 2, бит 0. Вход захвата таймера 1. По выбранному фронту значение 16-битного счётчика копируется в регистр захвата. |
| 10 | `P21` (`Tout1`) | Ввод/вывод | Порт 2, бит 1. Первый выход сравнения таймера 1, связан с OCR1. |
| 11 | `P22` (`SCLK`) | Ввод/вывод | Порт 2, бит 2. Тактовый сигнал последовательного интерфейса SCI. В зависимости от настройки SCI принимает внешние такты или выдаёт собственные. |
| 12 | `P23` (`Rx`) | Ввод/вывод | Порт 2, бит 3. При включённом приёмнике SCI служит входом последовательных данных. |
| 13 | `P24` (`Tx`) | Ввод/вывод | Порт 2, бит 4. При включённом передатчике SCI служит выходом последовательных данных. |
| 14 | `P25` (`Tout2`) | Ввод/вывод | Порт 2, бит 5. Второй выход сравнения таймера 1, связан с OCR2. |
| 15 | `P26` (`Tout3`) | Ввод/вывод | Порт 2, бит 6. Выход 8-битного таймера 2. Уровень или переключение выхода при совпадении задаёт регистр TCSR3. |
| 16 | `P27` (`Tclk`) | Ввод/вывод | Порт 2, бит 7. Внешний счётный вход таймера 2. |
| 17 | `P50` (`/IRQ1`) | Вход | Порт 5, бит 0. Первый внешний маскируемый запрос прерывания, активен при 0. Вектор $FFF8–$FFF9. |
| 18 | `P51` (`/IRQ2`) | Вход | Порт 5, бит 1. Второй внешний маскируемый запрос прерывания, активен при 0. Вектор $FFEA–$FFEB. |
| 19 | `P52` (`MR`) | Вход | Порт 5, бит 2. Memory Ready. Уровень 1 разрешает обычный цикл. При 0 удлиняется высокая фаза E для доступа к медленной внешней памяти. |
| 20 | `P53` (`/HALT`) | Вход | Порт 5, бит 3. Запрос остановки процессора. При 0 процессор завершает текущую команду и освобождает шину. |
| 21 | `P54` | Вход | Порт 5, бит 4. Цифровой вход общего назначения. |
| 22 | `P55` | Вход | Порт 5, бит 5. Цифровой вход общего назначения. |

## Регистры, связанные с выводами портов

| Порт | Ножки | Данные | Управление |
|---|---:|---|---|
| P2 | 9–16 | `$0003` | В регистре направления `$0001` **бит 0** управляет P20, **бит 1** — сразу всей группой P21–P27. Для обычного порта 0 означает вход, 1 — выход. При включении таймера или SCI направление соответствующих ножек P21–P27 задаёт периферия. |
| P5 | 17–24 | `$0015`, чтение | Все восемь ножек работают только на вход. У регистра управления `$0014` бит 0 разрешает IRQ1, бит 1 — IRQ2, бит 2 — MR, бит 3 — HALT. После сброса функции IRQ1 и IRQ2 выключены, MR и HALT включены. |
| P6 | 25–32 | `$0017` | Регистр направления `$0016` задаёт каждый бит отдельно. 0 — вход, 1 — выход. После сброса все восемь ножек работают на вход. |

[Порты и регистры, стр. 98–99, таблица 2 и рис. 14](https://www.jaapsch.net/psion/pdffiles/hd6303X_datasheet.pdf#page=13)
