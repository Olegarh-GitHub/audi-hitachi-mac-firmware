# Формат файлов разметки `.notes`

Из `.notes` и образа ПЗУ скрипт `tools/lst6303.py` собирает листинг `.lst`.
Листинг руками не правится — правится только `.notes`.

| Строка | Смысл |
|---|---|
| `# текст` | заметка для себя, в листинг не попадает |
| `legend` + строки `\| …` | легенда в начале листинга |
| `head D220` + строки `\| …` | заголовок перед адресом (шапка процедуры или блока) |
| `label D220 TASK0_TICK` | имя метки (латиницей) |
| `D220 текст` | комментарий к строке по адресу (4 hex-цифры в начале) |
| `entry D220 …` | дополнительная точка входа кода |
| `ptrtab D1C9 4` | таблица из 4 адресов (по 2 байта), все — точки входа кода |
| `noret D123` | подпрограмма не возвращается (после JSR на неё кода нет) |
| `table C000 256 текст` | таблица данных: адрес, длина в байтах, описание |
| `var 8018 текст` | ячейка ОЗУ или регистр: что хранит (идёт в список переменных) |

Пометки в тексте: без пометки — проверено по коду; `[Пр]` — предположение;
`[?]` — не известно; `[Изм]` — подтверждено замером на машине.

Покрытие: `python3 -I tools/lst6303.py ROM NOTES --cov` (или `--todo` со списком
непокрытых участков). Правила подсчёта — в начале `tools/lst6303.py`.
